# FTC DECODE
DECODE project built on the Roadrunner quickstart for the FTC SDK 11.0.0.
Includes XML and source files from work done over the summer of 2025 in project FtcIntoTheDeep_10.2_NDK,
which uses the Android c++ NDK and a JNI bridge to call an OpenCV application written in c++.

9/15/2025 Rebuilt this project without the c++ and JNI components because of a conflict with the
FTC VisionPortal. Defer the reintroduction of these components.
